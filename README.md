Using Angular and Ionic, the user can search for recipes based on ingredients. It uses Angular’s standalone components and Ionic UI components to create a responsive and user-friendly interface. Navigation between pages (Home, Recipe Details, Favourites, and Settings) was implemented using Angular routing.
An external recipe API was integrated which handles all HTTP requests and returns recipe data asynchronously. User inputs are bound to the application logic using two-way data binding, ensuring dynamic updates to the interface. Additional functionality, such as dietary filtering (vegetarian, vegan, and gluten-free) and theme customisation, was included to enhance usability and exceed the core project requirements. The application was tested and debugged within the required virtual machine environment.
